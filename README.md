# 📸 Face Recognition Attendance System

A Python-based Face Recognition Attendance System that automatically identifies registered students and records their attendance using a webcam.

## ✨ Features

- 👤 Student Registration
- 📷 Face Detection using OpenCV
- 🧠 Face Recognition using LBPH
- ✅ Automatic Attendance Marking
- 🚫 Prevents Duplicate Attendance
- 📊 Attendance Report
- 🖥️ User-Friendly GUI
- 🔐 Admin Login System

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Tkinter
- CSV
